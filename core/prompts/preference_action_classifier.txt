{previous_preferences}

{new_request}

{new_preferences}

YOUR TASK:
Analyze if the user wants to:
1. START FRESH - Clear all previous preferences and start a completely new search
2. MERGE - Keep previous preferences AND add the new ones (combine both)
3. REPLACE - Update specific attributes while keeping others (smart update)

DECISION CRITERIA:

START FRESH if:
- User says "new search", "start over", "forget that", "never mind"
- User's new request is completely unrelated (e.g., was looking at backpacks, now asks for clutches)
- User explicitly wants to clear previous filters

MERGE if:
- User is adding more filters (e.g., "also show blue ones", "add crossbody to the search")
- User says "and", "also", "in addition", "plus"
- New preferences are complementary (adding colors, brands, features)

REPLACE if:
- User says "just", "only", "instead", "switch to", "change to"
- User is correcting a preference (e.g., was $100 max, now says $200 max)
- User specifies one attribute should change (e.g., "make it red" means replace color)

Respond in this EXACT format:
```json
{{
  "action": "START_FRESH | MERGE | REPLACE",
  "confidence": "high | medium | low",
  "explanation": "Brief explanation of why this action",
  "clarification_needed": true/false,
  "clarification_message": "Optional: Ask user to confirm if confidence is not high"
}}
```
